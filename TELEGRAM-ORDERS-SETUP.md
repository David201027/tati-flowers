# Telegram-заказы TATI Flowers

Сайт уже формирует заказ на сервере, сохраняет его в `data/orders.json` и отправляет маме в Telegram.

## 1. Создать бота
В Telegram открыть **@BotFather** → `/newbot` → создать бота → скопировать токен.

В `.env`:

```env
TELEGRAM_BOT_TOKEN=сюда_токен
```

Токен нельзя вставлять в `public/app.js`, HTML или Google Sheets. Он должен оставаться только на сервере в `.env`.

## 2. Получить chat_id мамы
Мама открывает созданного бота и нажимает **START** (или отправляет `/start`). Бот не может первым начать личный диалог.

После этого в терминале проекта:

```bash
npm run telegram:chat-id
```

Скопировать найденную строку, например:

```env
TELEGRAM_CHAT_ID=123456789
```

в `.env`.

## 3. Проверить Telegram
Перезапустить сервер и выполнить:

```bash
npm run telegram:test
```

Маме должно прийти тестовое сообщение.

## 4. Как отправляется заказ
При нажатии клиентом кнопки оформления сервер:

1. заново получает актуальные цены из Google Sheets;
2. не доверяет цене из браузера;
3. формирует уникальный номер `TATI-YYYYMMDD-XXXXXX`;
4. сохраняет заказ в `data/orders.json`;
5. отправляет маме сообщение **«НОВЫЙ ЗАКАЗ — ожидает оплату»**;
6. отправляет клиента на оплату;
7. после подтверждения оплаты отправляет второе сообщение **«ЗАКАЗ ОПЛАЧЕН»**.

В Telegram приходят: номер заказа, дата, состав заказа, количество, цены, итог, имя, телефон, email, город, адрес, дата/время доставки и комментарий.

## 5. Локальная проверка без банковской карты
Пока `DEMO_PAYMENT=true`, после оформления откроется демонстрационная страница оплаты. Нажатие «Имитировать успешную оплату» помечает заказ оплаченным и отправляет второе сообщение в Telegram.

Для реальной оплаты позже переключить `DEMO_PAYMENT=false` и заполнить PayPlus-поля.
